# Projeto Vagas

Este é um projeto simples de gerenciamento de vagas desenvolvido em PHP com banco de dados MySQL. A aplicação permite que os usuários cadastrem, editem, excluam e pesquisem vagas de emprego, com a possibilidade de filtrar por status (ativa ou inativa).

## Funcionalidades

- **Cadastrar vaga**: Permite o cadastro de novas vagas de emprego.
- **Pesquisar vagas**: Realiza a busca por vagas cadastradas, podendo filtrar por status (ativa ou inativa).
- **Editar vaga**: Permite editar os dados de uma vaga existente.
- **Excluir vaga**: Exclui uma vaga do banco de dados.
- **Filtrar por status**: Filtra as vagas por status, permitindo visualizar apenas as vagas ativas ou inativas.

## Tecnologias Usadas

- **PHP**: Linguagem de programação para o desenvolvimento da aplicação.
- **MySQL**: Banco de dados utilizado para armazenar as vagas.
- **HTML/CSS**: Utilizados para a estrutura e estilo da interface de usuário.
